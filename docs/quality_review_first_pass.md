# 首次质量复查怎么做

这是第一次复查前的简单说明。先看清楚，再点按钮。第一轮不要急着合并事实值。

## 打开后看哪里

打开 GUI，进入“数据工程 / 质量复查”。

左边是 8 条待复查记录。点一条，右边会显示复查卡片。

右边重点看这几行：

- 复查摘要：这条数据是什么。
- 推荐操作：系统建议你先点什么。
- 为什么：为什么这条被标记出来。
- 外部证据：外部来源或审计证据说了什么。
- 合并影响：如果以后合并，会影响什么。

## 三个决定是什么意思

- 通过：这条可以进入下一步。低风险 metadata-only 标注可以考虑通过。通过不等于马上改事实值。
- 暂缓：现在证据不够，先放着。高风险项第一轮建议点暂缓。
- 拒绝：这条候选不需要处理，或者判断不可靠。

## 第一轮建议

第一轮建议保守一点：

- 高风险项：先点“暂缓”。
- 低风险 metadata-only 项：可以考虑点“通过”。
- 看起来只是来源精度差异的项：可以考虑“拒绝”，但不确定就先“暂缓”。
- 任何 value_change：第一轮不建议合并。

## 不会发生什么

只做复查决定不会写正式 triples，不会写 Chroma，不会写 Neo4j，也不会改变默认问答行为。

正式合并低风险标注前，先看 apply report。任何事实值变更都需要额外确认，不要在第一轮直接做。
